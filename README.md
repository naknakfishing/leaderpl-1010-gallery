# 우리 반 사이트 갤러리 (리더플 AI 스쿨 실습실 01)

이 저장소에 **내 사이트 소개 파일 하나**를 올리면, 1~2분 뒤 갤러리 사이트에 내 사이트 카드가 생겨요.

## 규칙 (클로드가 이 규칙대로 파일을 만들어 줘요)

1. 파일 위치와 이름: `sites/내-github-아이디.md`
   - 영어 소문자·숫자·하이픈(-)만. 예) `sites/sinyoung-shop.md`
   - **한 사람에 파일 하나.** 다른 사람 파일은 열지도 고치지도 않기
2. 파일 내용은 아래 형식 그대로 (`---` 사이 네 줄)
   ```
   ---
   title: 사이트 이름 (30자 안)
   oneline: 한 줄 소개 (60자 안)
   category: 업종 (15자 안, 예: 공방·클래스, 강의, 카페, 컨설팅)
   url: https://내사이트주소
   ---
   ```
3. **실명·전화번호·이메일은 넣지 않기.** 사이트 이름과 주소만.
4. `url`은 `https://` 로 시작하는 실제 열리는 주소. 아니면 카드가 생기지 않아요.
5. 다 만들면 **커밋 → 푸시**. 브랜치나 PR은 만들지 않아요(각자 다른 파일이라 겹치지 않아요).

## 푸시가 안 될 때

- 이 저장소에 **초대(Invite)를 수락**해야 푸시할 수 있어요. GitHub에서 온 메일이나 github.com 오른쪽 위 알림에서 **Accept invitation**.
- 그래도 안 되면 화면을 캡처해서 클로드에게 "설명부터 해 줘"라고 물어보세요.

## 운영 (리더플)

- 빌드: `node build.js` → `public/index.html` (패키지 설치 없음). Vercel 빌드 명령 `node build.js`, 출력 폴더 `public`.
- 검색 노출 끔(noindex, robots.txt Disallow). 수업 후 30일 유지 후 비공개 전환.
